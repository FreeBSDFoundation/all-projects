# FreeBSD Foundation CRA Update \- July 2026

## Summary

The majority of the work in July has centered around readiness for the September 11, 2026 deadline when manufacturers under the CRA must report actively exploited vulnerabilities and severe incidents that relate to products with digital elements that they have placed upon the European Union market. 

The FreeBSD Foundation is also obligated to report such incidents although the set of criteria that dictate this obligation are much less likely to be triggered for open source software stewards than they are for manufacturers. It is important, however, that both the FreeBSD Foundation and the FreeBSD Project Security Team are familiar with what the CRA reporting obligations are for manufacturers so that they can support manufacturers appropriately when manufacturers are going through the reporting process.

## Workstream updates

### Security, and vulnerability handling

In July, the Foundation met with members of the FreeBSD Core team to discuss the FreeBSD Project’s relationship with the FreeBSD Foundation as an open source steward under the CRA.

Work also began on creating a CRA reporting protocol for the FreeBSD Foundation to use in case of a security incident that requires handling under the CRA. This covers the Foundation’s obligations to report on actively exploited vulnerabilities and/or severe incidents that relate to FreeBSD through the European cyber security agency’s reporting platform. It also sets out the relative responsibilities for open source software stewards and manufacturers under the CRA so that we can avoid any confusion in the heat of the moment.

We also began drafting a cybersecurity policy for the FreeBSD Foundation which is a requirement for any open source software steward under the CRA. This will be finalized in collaboration with the FreeBSD security team and the aim will be to keep it as minimal as possible, referring to the security team’s existing material where possible. The Foundation will be offering this policy in a template form to the FreeBSD project so it can harmonize cybersecurity policies between any and all FreeBSD stewards.

### SBOM toolchain

The work on the SBOM toolchain is currently being reviewed and discussed for inclusion in the base system. There has been some useful feedback which may result in some architectural changes to the solution.

### Public documentation

Work on the permanent public CRA info pages for the FreeBSD Foundation is complete, however it is not yet published as the Core team would like to also provide public commentary on it when it is launched and they are currently working on this.
